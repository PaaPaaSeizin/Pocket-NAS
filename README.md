# PocketNAS

**Androidスマホを、自宅専用のNAS（ファイルサーバー）にするアプリです。**

余っているAndroidスマホに写真・動画・音楽・文書を入れておけば、普段のスマホやPCのブラウザからいつでも見られます。クラウドは使いません。月額料金もかかりません。ファイルは自宅のWi-Fiの中だけを移動します。

---

## 2つのアプリでできています

PocketNASは、役割の違う2つのアプリのセットです。

| アプリ | 入れる端末 | 役割 |
|---|---|---|
| **PocketNAS Server**（サーバー） | NASにしたいスマホ（余った端末など） | 指定したフォルダを自宅LANに公開する |
| **PocketNAS Manager**（マネージャー） | 普段使っているスマホ | サーバーに接続して、ファイルを見たり管理したりする |

このほかに、サーバーには**ブラウザ用画面（Web UI）**が内蔵されています。PCやタブレットからは、アプリを入れなくてもブラウザだけで使えます。

```
[NASにしたいスマホ]            [普段のスマホ]
  PocketNAS Server  ← Wi-Fi →  PocketNAS Manager
        ↑
        └── PCのブラウザ（Web UI）からもアクセスOK
```

---

## 主な機能

### サーバー（Server）
- スマホ内のフォルダを1つ選ぶだけで、その中身を自宅LANに公開
- マネージャーからの**自動発見**に対応。NFCタッチで接続先を受け渡す**NFCペアリング**も使えます
- ファイル一覧と検索を速くする**索引（インデックス）**を、充電中＋待機中に自動で作成
- 写真・動画・PDFの**サムネイル**を自動生成してキャッシュ
- **Web UI**内蔵（ブラウザからファイル操作とプレビューが可能）
- セキュリティ機能（任意設定）：サーバー全体の**アクセスパスワード**、フォルダごとの**パスワード**
- ゴミ箱、ZIP解凍、サーバーの状態表示（電池・空き容量・稼働時間）
- 常駐サービスとして動作し、端末を再起動しても自動でサーバーを再開

### マネージャー（Manager）
- ファイル一覧（リスト／グリッド切替、並び替え、名前検索、サーバー全体の検索、お気に入り、最近見たファイル）
- そのまま見られるプレビュー：
  - **写真**：左右スワイプで次々切替、ピンチで拡大
  - **動画**：前後の動画への切替付きプレイヤー
  - **PDF**：全ページをスクロール表示
  - **音楽**：フォルダ内を連続再生（リピート／シャッフル対応）
  - テキストファイルの内容表示
- ファイル操作：アップロード／ダウンロード、他のアプリへの共有、名前変更、移動、コピー、削除（ゴミ箱対応）、複数選択しての一括削除、フォルダ作成、ZIP解凍
- Androidの**「共有」メニューから直接アップロード**（ギャラリーで写真を選んで共有 → PocketNAS Manager → 保存先フォルダを選ぶだけ）
- **指紋／PINによるアプリロック**、サーバーパスワードの自動ログイン、パスワード付きフォルダの解除
- 一覧に写真・動画・PDFのサムネイルを表示

### Web UI（ブラウザ）
- アプリと同じようにファイルの閲覧とプレビュー（写真の前後切替、PDFの全ページ表示、音楽の連続再生）
- 今いるフォルダや開いているファイルがURLに反映されるので、ブラウザの「戻る」や再読み込みがそのまま効きます
- アップロード／ダウンロード、検索、ゴミ箱、ダークテーマ対応

## 使い方

1. **サーバー側の準備**
   NASにしたいスマホに「PocketNAS Server」をインストールし、共有したいフォルダを選んでサーバーを開始します。

2. **マネージャー側の準備**
   普段のスマホに「PocketNAS Manager」をインストールします。
   ※ サーバーとマネージャーは、**同じWi-Fi**につないでください。

3. **接続する**
   マネージャーを開くと、サーバーを自動で探して接続します。
   見つからないときは、サーバーのスマホにNFCでタッチするか、サーバーのIPアドレスを手動で入力してください。

4. **使う**
   ファイルを選べばそのまま写真・動画・PDF・音楽を再生できます。
   右下の「＋」ボタンから、スマホ内のファイルをアップロードできます。

5. **PCから使う場合**
   ブラウザで `http://（サーバーのIPアドレス）:8080` を開くと Web UI が使えます。

---

## 動作環境

- Android 8.0（API 26）以上の端末
- サーバーとマネージャー（またはブラウザ）が同じLAN／Wi-Fiに接続されていること
- インターネット接続は不要です

## セキュリティについての注意

- PocketNASは**家庭内LAN専用**の設計です。ルーターのポート開放などで、インターネットに直接公開しないでください。
- 初期状態ではパスワードは設定されていません（LAN内のみで使う前提）。必要な場合は、マネージャーのサーバー状態画面からアクセスパスワードを設定できます。特定のフォルダだけにパスワードをかけることもできます。

## 開発者向け情報

- 言語：Kotlin（minSdk 26 / targetSdk 34）
- 構成：
  - `app-server`：Ktor ベースのHTTPサーバー。Storage Access Framework（SAF）でフォルダにアクセスし、NSD（mDNS）で存在を通知、NFC（HCE）でペアリング情報を渡します。インデックスはSQLiteに保持し、WorkManagerで定期更新します。
  - `app-manager`：OkHttp クライアント＋Media3 プレイヤー。Material 3 UI。
- ビルド：Android Studioでプロジェクトを開き、各モジュール（`:app-server` / `:app-manager`）をビルドしてください。
